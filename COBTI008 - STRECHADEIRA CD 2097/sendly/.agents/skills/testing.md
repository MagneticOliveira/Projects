# Skill: Testing

## Objetivo

Validar comportamento real.

## Casos

Sempre que possível testar:

### Caso positivo

Entrada válida.

### Caso negativo

Entrada inválida.

### Caso limite

Valores extremos.

### Regressão

Verificar se comportamento existente continua funcionando.

## API

Verificar:

- método;
- URL;
- parâmetros;
- HTTP status;
- resposta;
- tratamento de erro.

## Frontend

Verificar:

- campos;
- mensagens;
- redirecionamentos;
- sessionStorage/localStorage quando utilizado;
- integração com API.

## Banco

Verificar:

- quantidade de registros;
- duplicações;
- NULL;
- filtros;
- consistência.

## Regra

Não afirmar que passou em um teste que não foi executado.
