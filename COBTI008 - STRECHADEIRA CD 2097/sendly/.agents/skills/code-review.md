# Skill: Code Review

## Checklist

### Código

- legibilidade;
- duplicação;
- complexidade;
- nomes;
- tratamento de erros.

### Backend

- endpoints;
- validação;
- HTTP status;
- segurança;
- SQL.

### Frontend

- fetch;
- responsividade;
- UX;
- erros;
- armazenamento local.

### Banco

- joins;
- duplicações;
- filtros;
- performance.

### Segurança

- senhas;
- tokens;
- secrets;
- logs.

### Compatibilidade

Verificar se alterações quebram funcionalidades existentes.

## Resultado

Classificar problemas como:

CRÍTICO
ALTO
MÉDIO
BAIXO

Não atribuir nota geral ao código.

Corrigir problemas críticos e altos antes de concluir.
