# Skill: Architecture

## Objetivo

Definir a menor arquitetura necessária para implementar o requisito.

## Regras

Primeiro analisar a arquitetura existente.

Identificar:

- frontend;
- backend;
- banco;
- integrações;
- autenticação;
- deploy.

Não criar novas camadas sem necessidade.

Preferir reutilizar componentes existentes.

## Resultado

Produzir:

- fluxo;
- arquivos afetados;
- dependências;
- riscos;
- estratégia de implementação.

Sempre explicar por que uma alteração arquitetural é necessária.
