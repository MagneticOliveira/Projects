# Skill: Requirements

## Objetivo

Transformar uma solicitação em requisito implementável.

## Processo

1. Interpretar a solicitação.
2. Identificar objetivo.
3. Identificar usuários envolvidos.
4. Identificar entradas.
5. Identificar processamento.
6. Identificar saída.
7. Identificar regras.
8. Identificar critérios de aceite.
9. Identificar pendências.

## Formato

### Objetivo

Descrever o que deve ser feito.

### Fluxo

Descrever o comportamento esperado.

### Regras

Listar regras de negócio.

### Critérios de aceite

Definir como saberemos que está funcionando.

### Arquivos provavelmente envolvidos

Listar somente arquivos confirmados ou prováveis.

### Pendências

Registrar informações que precisam ser confirmadas.

Não inventar respostas para pendências.
