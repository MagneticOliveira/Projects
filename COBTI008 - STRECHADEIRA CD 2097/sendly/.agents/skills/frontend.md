# Skill: Frontend

## Tecnologias

- HTML;
- CSS;
- JavaScript.

## Regras

Manter separação entre:

- estrutura;
- estilo;
- comportamento.

Não adicionar framework sem necessidade.

## Fetch

Sempre tratar:

- sucesso;
- HTTP error;
- erro de rede;
- resposta inválida.

## Responsividade

Verificar:

- desktop;
- tablet;
- celular.

## UX

Mensagens devem ser curtas e profissionais.

Preferir Toast para feedback de ações.

Evitar `alert()` no produto final.

## Tema escuro

Verificar contraste de:

- textos;
- imagens;
- logos;
- botões;
- campos;
- ícones.

Não permitir que uma logo desapareça em navegadores configurados para modo escuro.
